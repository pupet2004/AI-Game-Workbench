01 · The problem changed

Agent 已经越来越能做事。
真正难的是：项目能不能持续存在？

当一次执行从“回答一段代码”变成数小时的阅读、修改、测试、恢复与迭代，Session 开始被迫承担它并不擅长承担的角色：项目状态容器。

01Session 越来越长

历史不断累积，每次重新加载的 token 和注意力成本持续增长。

02新 Session 不知道旧 Session 做过什么

项目认知依赖聊天窗口，换会话就要重新解释。

03Summary 会发生语义漂移

“暂时考虑”经过多轮压缩，可能悄悄变成“已经决定”。

04Agent 说“完成” ≠ 项目真的完成

执行结果、自然语言声明与正式项目状态被混在一起。

05运行中断，项目跟着失忆

崩溃、限流、重启之后，人重新成为上下文恢复器。

06Agent 越多，人反而越像调度器

不断切窗口、回忆状态、检查输出、决定下一步，人类注意力成为瓶颈。

08 · Defense in depth

错误可以发生。
但不应该自动跨层传播。

Workbench 的工程价值，不是保证 Agent 永远正确，而是让一次局部错误尽量停留在它发生的层级，并保留重新判断与恢复的路径。

Worker 判断错了
它仍然可以产生 Claim 与 Handoff。
不会自动变成 Accepted State。
Handoff 写错了
错误可以被继续当作 Context 读取。
Context 不拥有 Authority。
Leader 读到旧状态
它可能基于旧 Project World 做判断。
CAS 阻止旧认知静默覆盖新世界。
Worker 崩溃了
Runtime 中断，但项目已经留下执行状态。
Runtime Failure ≠ Semantic Reset。
Library 过期了
Derived knowledge 可能不再反映当前正式状态。
Library 不能反向修改 Canonical State。
Provider 换了
执行 Agent、模型与工具链发生变化。
Project World 不需要跟着重建。
09 · Engineering muscle

真正让架构跑起来的，
是这些可验证边界。

Kernel 已冻结。当前实现把身份、执行前提、Completion、Authority、恢复、产品壳与 Provider 生命周期分开，并用真实桌面 gate 防止它们重新混回一条“聊天状态”。

Canonical Acceptance Spine

Completion → Evidence / Claim / Handoff → Review → Authority Decision → AcceptedProjectState。Completion、Evidence、Summary 都不能绕过 Authority 改变项目真相。

BaseCommit + Execution Preconditions

Worker 启动时冻结关键前提，使验证结果明确绑定到代码版本、任务修订与执行配置；历史完成工作不会重新冒充当前工作。

Immutable Authority History + Projection

正式状态变化以不可变 Authority 历史存在；AcceptedProjectState 从历史重建，因此“现在是什么”和“为什么变成这样”可以同时回答。

Crash / Restart Recovery

恢复的是 Project State、Worker execution、pending review、successor routing 与上下文，而不是复活原 Agent 的“心理状态”。真实认证包含正常托盘退出与进程重开。

Product Shell

Overview / Work / Review / World / History / Settings 已收束为用户语言：项目现在是什么、Agent 正在做什么、有什么待决定、项目为什么变成这样。

Verification Classification

路径与交付物范围可机器分类；无法可靠机器判断的自由文本 acceptance criteria 保留 NotVerifiable，不用“全绿”掩盖能力边界。

Provider-owned Authentication

Workbench 只发起 OpenCode 自己的登录流程，不读取或保存 credential；登录完成后必须重新 runtime probe，只有真实可用才进入 Ready。

Git / Distribution Boundary

Git 负责文件历史；Workbench 负责项目语义与治理。Windows self-contained 包采用 per-user 安装，程序文件与 Project World 数据分离。
