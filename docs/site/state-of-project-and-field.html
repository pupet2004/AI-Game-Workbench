06 · Honest Positioning

现在能说什么，
仍然不能说什么。

Workbench 已经越过“架构是否能闭环”的阶段，但公开 Alpha 仍应把证据边界写清楚。可信度来自：证明到哪里就说到哪里。

We can honestly claim

  • Canonical Acceptance Spine 已通过 deterministic certification、真实 Codex 与真实桌面产品闭环验证。
  • First-use UI 从空白 Workbench 配置完成 +2 → Reset → High Score 三轮；六次正常退出 / 重开后 Accepted State 与 Leader continuity 保持一致。
  • Overview / Work / Review 已产品化；Accept / Request revision / Reject 均经过 Preview → Confirm，且 Completion / Evidence / Summary 不能绕过 Authority。
  • Verification scope / declared-deliverable 分类已修复并通过 gate；无法机器证明的自由文本 criteria 会保留 NotVerifiable。
  • Codex 与 OpenCode + deepseek/deepseek-v4-flash 已有真实路径；OpenCode credential 由 Provider 自己保存，Workbench 不读取或持久化凭据。
  • Windows self-contained ZIP、per-user installer、Environment Readiness 与卸载隔离烟测已经完成。

We must NOT claim yet

  • “已经完整解决长期 Agent 协作。”
  • “所有 Provider、模型与游戏引擎都已真实 E2E 支持。”
  • “自由文本 acceptance criteria 都可以自动可靠验证。”
  • “已经完成陌生 Windows 机器 / 全新用户的独立 clean-machine 认证。”
  • “UI automation 等价于陌生人真实可用性研究。”
  • “Authority commit 与外部 runtime 启动是一个跨系统原子事务。”
