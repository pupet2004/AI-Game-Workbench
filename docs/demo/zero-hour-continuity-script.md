# Zero Hour Continuity Demo Path

1. Open or create the Zero Hour project and establish its Project World through the existing setup flow.
2. Show Accepted State: single closed timeline; dangerous time interventions; protagonist conflict is freedom/choice.
3. In the existing Leader surface, request a bounded Chapter 1 task: ordinary life under the system; no rebellion; do not change the single-timeline rule.
4. Start the currently supported Worker path and produce `chapter-01.md`.
5. Show the completion/Handoff presentation with result, artifact, changed paths, unresolved issues, recommendations, and provenance.
6. Retain “time permit” as a Proposal and preserve “single closed timeline” as Accepted Fact.
7. Search Library for both terms and show their different authority labels.
8. Rotate/reopen the Leader session.
9. Show “Recovered from Project World”: Chapter 1 completed, its established elements, remaining work, and constraints that remain accepted.

Demo success screen: the agent/session changes while Project World, accepted constraints, Handoff evidence, and retrievable project knowledge remain.

Stop condition: if any step requires merging B1 and Legacy Worker identity or authority models, stop and report the gap.
