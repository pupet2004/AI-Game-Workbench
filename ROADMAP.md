# Roadmap

## Architecture Preview -- August 27, 2026

Prepared for publication:

- architecture and design principles;
- English and Chinese whitepapers;
- experimental implementation and reference material;
- known limitations and research questions; and
- the MIT license.

The implementation workspace already contains a Windows-first Alpha candidate and a local WEIQI³ acceptance record. This document-only package keeps the architecture discussion separate from the binary distribution.

Not claimed at this stage:

- a polished public software release;
- quantified token or time savings;
- longitudinal continuity results;
- public heterogeneous-agent routing evidence; or
- multi-user governance.

## Before Broad Public Alpha Release

The first software release should demonstrate a coherent end-to-end project loop:

1. Create or import a project.
2. Establish project identity and responsibilities.
3. Record a Claim, make a Decision, and inspect the Accepted State.
4. Resume work from a Handoff with a new participant.
5. Attach basic evidence and trace a decision back to its source.
6. Complete the workflow without relying on undocumented operator knowledge.

The release should also include a reproducible demo, clear installation steps, checksums for distributed binaries, release notes, and a statement of supported platforms.

## Evidence After Alpha

- A cross-agent handoff demonstration.
- A controlled comparison of cold-start recovery versus Workbench recovery.
- Measurements for tokens, elapsed time, and decision recovery accuracy.
- Feedback from sustained, real project use.
- Multi-user authority delegation and conflict-resolution experiments.

The roadmap is ordered by evidence and user experience, not by feature count.
